# Agent 开发的本质

## 一、核心认识

大模型本身只有"生成文本"这一种输出方式，它知识渊博、推理强大，却无法直接读文件、查数据库、发请求、改代码或操作系统——像一个被束缚了手足的头脑。

Agent 开发的本质，就是为这个头脑接上"手足"，让它能把"知道"变成"做到"。

## 二、Agent 的完整构成

> Agent = 大模型 + 工具 + 循环 + 规划 + 约束

1. **工具（手足）**：通过工具函数（tools）让模型的意图能作用于外部世界。
2. **反馈（感官）**：工具执行的结果要回传给模型，形成"调用—观察—再决策"的闭环（ReAct 式循环），否则只是单向喊话。
3. **规划（协调）**：决定什么时候用哪个工具、参数怎么填、失败了怎么重试，靠提示词、流程编排或模型自身的规划能力实现。
4. **约束（规矩）**：工具权限、错误处理、人工确认，避免"乱动手"。

## 三、一句话总结

大模型是"有知识却被束缚的头脑"，Agent 开发就是为它接上手足、感官、协调与规矩，让它在真实世界里"想得到，也做得到"。
