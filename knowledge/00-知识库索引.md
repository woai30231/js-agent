# Agent 开发学习知识库

> 本知识库面向正在学习「AI Agent 开发」的开发者，内容覆盖从 Agent 基础概念到工程化落地的完整链路。
> 它同时是为后续 **RAG（检索增强生成）学习**准备的数据源——每一篇文档都刻意写成分段完整、语义独立的结构，
> 方便之后做文档切块（chunking）、向量化（embedding）与相似度检索的演示。

---

## 一、关于本知识库

### 1.1 它是什么

这是一套围绕「如何从零构建一个能调用工具的 AI Agent」的中文技术文档。它的内容与一个真实的
Node.js 学习项目（agent-study-1）一一对应：文档里讲的概念，都能在那个项目的源码里找到落点。

### 1.2 它解决的问题

- 想搞懂 Agent 和普通聊天机器人到底有什么区别
- 想知道模型是怎么"调用工具"的，背后是什么协议
- 想理解流式输出、重试、上下文管理这些工程细节为什么必须做
- 想为学习 RAG 准备一份结构清晰、内容充实的数据源

### 1.3 使用方式

- **按顺序通读**：从 01 读到 10，适合系统性入门
- **按问题查阅**：直接跳到 FAQ（10）或对应主题文档
- **作为 RAG 数据源**：后续学习 RAG 时，把本目录下的 Markdown 文件喂给切块与向量化流程

## 三、推荐学习路径

### 路径 A：纯理论入门（不写代码）

1. 先读 `01-Agent基础概念.md`，建立整体认知
2. 再读 `02-ReAct循环与工具调用.md`，理解 Agent 的运转方式
3. 最后读 `08-RAG与知识增强.md`，衔接下一阶段 RAG 学习

### 路径 B：边学边写代码（推荐）

按下面顺序，每读完一篇，就在自己的项目里找到对应代码：

1. `01-Agent基础概念.md` → 观察 `src/agent.js` 的整体结构
2. `02-ReAct循环与工具调用.md` → 看 `runAgent` 的 for 循环
3. `03-函数调用协议.md` → 看 `src/tools.js` 的 toolSchemas 和 runTool
4. `05-流式输出与错误处理.md` → 看 `src/llm.js` 的 fetch 与解析
5. `06-安全与沙箱.md` → 看 `src/tools.js` 里的路径校验逻辑
6. `07-可观测性与调试.md` → 看 trace 和 usage 相关代码

### 路径 C：只为 RAG 数据源

如果你只关心 RAG，重点阅读 `08-RAG与知识增强.md`，并把本目录所有 `.md` 文件当作
后续切块、向量化、检索的输入。

## 四、为 RAG 学习做的准备说明

本知识库在写作时有意遵循以下约定，以便后续 RAG 流程能拿到高质量片段：

1. **每篇文档独立成篇**：一个主题一篇，不跨文件引用大段内容
2. **段落语义完整**：每个小节能独立阅读，不依赖前文才能看懂
3. **标题层级规范**：统一使用 `#` / `##` / `###`，方便按标题切块
4. **代码块独立**：代码示例用围栏代码块包裹，方便单独抽取
5. **FAQ 条目化**：每个问答独立成段，适合做"问题-答案"对

> 后续学习 RAG 时，建议的切块单位是「小节（## 标题）」，而不是固定字符数——语义完整的块，
> 检索质量通常优于机械切分。

## 五、术语约定

| 术语 | 含义 |
| --- | --- |
| LLM | 大语言模型（Large Language Model），如 DeepSeek、GPT、Claude |
| Agent | 能自主决策、调用工具、多轮执行任务的智能体 |
| Tool | 智能体可调用的外部能力（查时间、算数、读文件等） |
| tool_calls | 模型决定调用工具时返回的调用指令 |
| ReAct | "推理 + 行动"的 Agent 执行范式 |
| SSE | Server-Sent Events，服务端推送流式数据的协议 |
| RAG | 检索增强生成（Retrieval-Augmented Generation） |
| chunk | 文档切块后得到的最小检索单元 |
| embedding | 把文本转成向量表示的技术 |
